[day1-2] TCP Echo Server

소켓 생성부터 fork() 기반 다중 클라이언트 처리까지

  • socket / bind / listen / accept
  • fork()로 자식 프로세스에서 클라이언트 처리
  • waitpid()로 좀비 프로세스 방지
int server_fd = socket(AF_INET, SOCK_STREAM, 0);
bind(server_fd, (struct sockaddr *)&addr, sizeof(addr));
listen(server_fd, 128);
int client_fd = accept(server_fd, NULL, NULL);

[day3-4] epoll Echo Server

select/poll의 O(n) 한계를 극복한 이벤트 기반 I/O

  • epoll_create1(0) — epoll 인스턴스 생성
  • epoll_ctl — fd 등록 / 수정 / 삭제
  • epoll_wait — 이벤트 발생한 fd만 반환 (O(1))
  • LT(Level Trigger) vs ET(Edge Trigger)
int epfd = epoll_create1(0);
ev.events  = EPOLLIN;
ev.data.fd = listen_fd;
epoll_ctl(epfd, EPOLL_CTL_ADD, listen_fd, &ev);
int nready = epoll_wait(epfd, events, MAX_EVENTS, -1);
